# Code of conduct

Treat contributors respectfully. Welcome different perspectives and make participation accessible. Explain technical disagreements with evidence.

Harassment, discrimination, threats, doxxing, impersonation and unwelcome sexual attention are unacceptable. Respect privacy. Contact the repository owner through GitHub to arrange private reporting. Maintainers may remove harmful content, warn, restrict or ban participants proportionally. Maintain confidentiality and apply these standards equally to maintainers.
